# Daemon Manual changelog

The site name stays Daemon Manual V0.77. These are the site versions, newest first. The same notes show in the What's new screen.

## 0.90 · November 2026
- Every rule number and rule table lives in one block at the top of the code (DM RULES). The Rules page and the character sheet both read from it, so they always match and a DM note is a one-line change.
- The Rules page builds its hacks, clip, ammo, Net program, jack-out, hot-swap, fabrication, dismemberment and tier damage tables from that block.
- Panels draw in when a page or tab opens, Arwes style. Motion off or Calm turns it off.
- New sounds for eddies and the shop, handouts and cyberware cards. Gig payouts and the crew stash had no sound before. Every sound was measured and leveled so each group sits at one volume.
- A What's new screen that shows once after each update. Open it again from the version number at the bottom of any page or from Settings, Controls.
- Design cleanup. 161 one-off styles became shared classes.

## 0.85 · November 2026
- Backups on the Mercs page (download, copy as text, restore) and an automatic copy of every merc before an update.
- A warning if a phone runs out of storage for the site.
- A welcome card for new players and three first-sheet tips.
- Accessibility pass. Skip link, real buttons everywhere, keyboard support on the vitals bar, clearer focus, better contrast.
- Rules and DM screens fold up on phones.
- Death saves follow the DM's notes.
- Bottom tabs on phones, live backgrounds, a smooth jack-in and a full design language pass.
